## Grainy RS 0.5.1

Grainy RS 0.5.1 restores the interactive **Auto Color Strength** slider and upgrades the **Ask AI** and **AI Connection (MCP)** UX.

### What's New
- **Auto Color Strength Slider (`자동 색 세기`, 0–100%)**:
  - Applying **Auto Color (`자동 색` / `Ctrl+Shift+U`)** now reveals the live **Auto Color Strength** slider right under the Basic panel's quick action row.
  - Dragging the slider (or fine-adjusting with `↑/↓` and `Shift+↑/↓` inside its number box) blends the auto-color RGB channel curves smoothly in real time on the GPU, saves your preferred strength (`auto_color_amount`) across photos and batch runs, and commits a clean Undo step.
- **Ask AI Model Preset Dropdown & AI Connection Bridge**:
  - **Ask AI (`AI에게 시키기`)** now provides a per-program recommended model dropdown (Claude Code: Sonnet / Opus / Haiku; Codex: GPT-5.4 / GPT-5.3 Codex / GPT-5.4 Mini / o3; Gemini CLI: Gemini 2.5 Pro / Gemini 2.5 Flash) alongside custom model ID entry and program-default mode.
  - Switching AI programs automatically clears incompatible preset IDs from the previous provider.
  - **Settings → AI Connection (MCP)…** now includes a direct **Ask AI (Sign In · Model)…** button so program login and model selection are one click away.

On Windows, extract the complete ZIP and run `GrainyRS.exe` (or update directly from inside Grainy RS). On macOS (Apple Silicon and Intel, macOS 11.0+), open the universal DMG and drag `Grainy RS` into Applications. The matching `.sha256` files let you verify each download.
