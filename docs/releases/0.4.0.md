## Grainy RS 0.4.0

Grainy RS 0.4.0 delivers a major leap in GPU editing responsiveness, Process Version 4 image quality, large-catalog scalability, local AI masking, and full macOS Universal native parity alongside Windows x64.

- **Zero-Copy Shared GPU Viewport & GPU Monitor ICC 3D LUT**: `grainy-gpu` now shares `eframe`'s `wgpu::Device` (`DX12` on Windows, `Metal` on macOS) and presents directly into VRAM textures without full-frame CPU readbacks. Monitor ICC profiles (including Display P3 and ProPhoto working space) evaluate via a GPU 33³ tetrahedral 3D LUT alongside GPU histogram and clipping overlays. On an RTX 3070 with Display P3 ICC, slider preview latency dropped from 140.5 ms to 18.3 ms at `2048×1365` (7.7×) and from 414.4 ms to 11.3 ms at `4000×2667` (36.6×).
- **Single-Submit GPU Pipeline & Zero-Readback Wavelet Denoise**: Batched command submission, GPU double-float wavelet noise-profile reductions, 5-tap à-trous filters, and register-only 5×5 median sorting accelerate GPU detail previews by 3.4×–4.0× with unchanged numerical parity.
- **Process Version 4 (`프로세스 4 · Grainy RS 네이티브`)**: Selectable in Camera Calibration while preserving 100% Process 3 compatibility. Includes clipped-channel RAW highlight reconstruction, 12-stop unclipped log-luminance Highlights/Shadows with a hue-preserving C³ filmic shoulder, halo-free Fast Local Laplacian Pyramid Clarity (26.5× GPU vs CPU), edge-aware luminance Texture, Guided-Filter Dehaze, and structure-adaptive cross-scale wavelet luminance denoising.
- **True 1:1 Viewport Tile Rendering**: Zooming to 1:1 renders only the visible viewport region with a 96 px halo and shared whole-frame tone base. On a 45 MP (`8192×5464`) frame, 1:1 slider drag latency fell from 929.9 ms to 9.59 ms (>100 fps, 96.9× faster).
- **500K-Scale DAM Catalog Optimization**: Tuned SQLite memory/WAL connections, zero-lock clean queries, incremental folder total triggers, O(F log F) folder tree construction, and single-connection `json_extract` listings cut 100,000-photo indexing+search from 73.4 s to 1.46 s (50.3×), warm filename search from 46.3 ms to 2.94 ms (16.2×), and 200-folder switching from 277.1 ms to 5.71 ms (48.5×).
- **Upgraded Local AI Masking (Windows & macOS)**:
  - Added 3-channel RGB Guided-Filter matte refinement for fine hair/fur/silhouette edges and a new **Portrait Skin (`인물 피부 선택`)** mask mode.
  - **Windows**: Cached WinML sessions with DirectML GPU/NPU (`DirectXHighPerformance`) acceleration and automatic CPU fallback.
  - **macOS**: Built-in offline Apple Vision Neural Engine segmentation (`VNGenerateForegroundInstanceMaskRequest` on macOS 14+ for Subject/Background/Object and `VNGeneratePersonSegmentationRequest` on macOS 12+ for Portrait Skin) requiring zero model downloads.
- **Native macOS Metal FP16 EDR HDR Monitor Window**: MacBook Pro XDR, Pro Display XDR, and external HDR monitors can now open the dedicated native HDR preview window (`CAMetalLayer` `RGBA16Float`, Extended Linear sRGB) matching Windows D3D11 scRGB support.
- **Core Reliability & Format Fixes**: Thread-safe LittleCMS time handling, per-thread cached RAW ProPhoto→sRGB transforms, Canon CR3/Fujifilm RAF EXIF preservation on export, multithreaded AVIF/HDR AVIF encoding, parallel HDR/panorama merge & preview hashing, multi-OS release updater fallback, and embedded Grainy icon across main and HDR windows.

On Windows, extract the complete ZIP and run `GrainyRS.exe`. On macOS (Apple Silicon and Intel, macOS 11.0+), open the universal DMG and drag `Grainy RS` into Applications. The matching `.sha256` files let you verify each download.
