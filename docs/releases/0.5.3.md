## Grainy RS 0.5.3

**Grainy RS no longer quits without a message when another program gives its window a size it cannot draw.**

### 고친 점
- 스크립트나 창 관리·화면 캡처 도구 같은 다른 프로그램이 Grainy RS 창을 그래픽카드가 그릴 수 있는 크기(보통 16384~32768픽셀)나 모든 모니터를 합친 크기보다 크게 만들면, Grainy RS가 아무 메시지 없이 꺼졌습니다. 이제는 꺼지지 않고 창이 모니터 크기로 돌아옵니다.
- 창을 잠깐 그리지 못한 뒤에도 화면이 검게 남지 않고 다시 그려집니다.
- 아주 작은 창(1×1), 크기가 0인 창, 최소화도 모든 화면에서 안전한지 확인하는 자동 검사를 더했습니다.

### Fixed
- **No more silent quit on a window that is too large to draw.** When another program (a script, a window manager, a screen capture tool) made the Grainy RS window larger than the graphics card can draw (usually 16384 to 32768 pixels) or larger than all the monitors together, Grainy RS quit without a message. Now it keeps running and the window goes back to the size of its monitor.
- After a moment the window could not be drawn, it draws again instead of staying dark.
- New automatic tests draw the window at every size down to 1 × 1 and 0 × 0 (and minimised) in every view.

On Windows, extract the complete ZIP and run `GrainyRS.exe` (or update directly from inside Grainy RS). On macOS (Apple Silicon and Intel, macOS 11.0+), open the universal DMG and drag `Grainy RS` into Applications. The matching `.sha256` files let you verify each download.
