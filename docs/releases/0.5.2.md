## Grainy RS 0.5.2

**Grainy continues as Grainy RS.** This version brings the Python Grainy's library over, so people who used the Python Grainy can move with their photos and edits. The Python Grainy gets no more updates after its last version, 0.6.9.

### 파이썬판 Grainy를 쓰던 분
- Grainy RS는 따로 설치되는 별도 프로그램이라 파이썬판 Grainy를 바꾸지 않습니다.
- 라이브러리가 빈 상태로 처음 켜면, 파이썬판 라이브러리(사진, 보정, 기록, 컬렉션, 썸네일, 카메라 프로필)를 가져올지 한 번 묻습니다. 파이썬판 라이브러리는 읽기만 하고 바꾸지 않습니다. 가져오기 전에 파이썬판을 닫아 주세요.
- 나중에 파일 관리 메뉴 › "파이썬 Grainy 라이브러리 가져오기…"로도 가져올 수 있습니다. Grainy RS에 이미 사진이 있으면 먼저 묻고, 기존 라이브러리를 백업한 뒤 바꿉니다(파일 관리 메뉴 › "카탈로그 복원"으로 되돌릴 수 있습니다).
- 파이썬판에서 AI 연결(MCP)을 쓰셨다면 가져오기를 마친 창에 "AI 연결 열기" 버튼이 나옵니다. 그 창에 나오는 명령을 한 번 실행하면 예전 grainy 연결이 Grainy RS 연결로 바뀝니다.

### What's New
- **Import the Python Grainy's library**: on the first start with an empty library, Grainy RS offers once to bring over the Python Grainy's library (photos, edits, history, collections, thumbnails, camera profiles). It reads a snapshot copy and never changes the Python library. The same import is in the *File management* menu (*Import the Python Grainy Library…*); a library that already has photos is asked about and backed up first.
- **AI connection**: the install lines for Claude Code and Codex now replace an earlier `grainy` entry (such as the Python Grainy's), so the AI programs talk to Grainy RS.

On Windows, extract the complete ZIP and run `GrainyRS.exe` (or update directly from inside Grainy RS). On macOS (Apple Silicon and Intel, macOS 11.0+), open the universal DMG and drag `Grainy RS` into Applications. The matching `.sha256` files let you verify each download.
