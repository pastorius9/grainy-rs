## Grainy RS 0.5.4

**Stability release: fixes from a full code review. The most important one: opening an ordinary photo folder as a library could delete some photos in it.**

### 고친 점
- **사진이 지워질 수 있던 문제.** 사진 폴더를 '라이브러리 폴더 열기'로 열었을 때, 그 안의 `previews`·`thumbnails` 폴더에 있는 숫자 이름 사진(예: `2024.jpg`)을 Grainy RS가 쓰지 않는 캐시로 보고 지울 수 있었습니다. 이제 Grainy RS가 직접 만들었다고 확인된 썸네일만 정리합니다.
- **내보내기가 끝나지 않던 문제.** 메타데이터를 포함해 내보낼 때 몇몇 GPS 위치(예: 2°23′0″)에서 내보내기가 멈췄습니다.
- **편집이 사라지지 않게.** 정전이나 강제 종료 직전에 저장한 보정도 남도록 저장 방식을 강화했습니다. 같은 라이브러리를 두 창에서 동시에 고칠 수 없게 했습니다.
- **라이브러리를 바꾼 뒤 키워드가 덮어써지던 문제**를 고쳤습니다.
- **파이썬판 라이브러리 가져오기를 더 안전하게.**
  - 외장 드라이브에서 원본 파일이 덮어써질 수 있던 경로를 막았습니다.
  - 가져오는 도중 다른 라이브러리로 바꿔도 엉뚱한 라이브러리가 바뀌지 않습니다.
  - 중간에 멈춰도 카메라 프로필이 깨지지 않습니다.
  - 원본이 연결되지 않은 사진에 다른 사진이 보이지 않습니다.
- **RAW:**
  - 아이폰 ProRAW(DNG)가 열립니다.
  - 좌우 반전된 RAW의 썸네일 방향과 크기가 맞습니다.
- **보정:**
  - 'AI 노이즈 제거'만 켰을 때 미리보기·GPU 내보내기·복사·동기화에서 빠지지 않습니다.
  - 1:1 확대 중에도 히스토그램과 클리핑 표시가 바로 바뀝니다.
  - HDR 사진에서 부분 대비가 밝은 부분을 자르지 않습니다.
- **파일:**
  - AVIF 반투명 부분의 색이 맞습니다.
  - AVIF·JPEG XL로 내보낸 파일을 다시 열어도 카메라 정보가 남습니다.
  - 비정상적인 사진 파일 하나가 메모리를 지나치게 쓰지 않습니다.
- **AI 연결(MCP):** 내보내기·가져오기·자동 톤이 끝날 때까지 기다리지 않고 바로 작업 번호를 돌려줍니다. RAW 10장 내보내기 요청은 전에 약 40초 멈췄습니다.
- **AI에게 시키기:** 입력한 문장이 프로그램 옵션으로 해석되지 않습니다. 작업 폴더에 있는 같은 이름의 프로그램을 실행하지 않습니다.
- **반응:**
  - 사진 위에서 마우스를 움직일 때 멈칫하지 않습니다.
  - 사진이 많을 때 선택 표시가 느려지지 않습니다.
- **기타:**
  - GPU 가속을 끄면 내보내기에서도 GPU를 쓰지 않습니다.
  - 파노라마 병합을 취소하면 엉뚱한 오류 없이 끝납니다.
  - 그래픽카드 연결이 끊겼을 때 더 안전하게 처리합니다.
- **macOS:**
  - 업데이트가 실패해도 앱이 사라지지 않습니다.
  - 설정 파일은 본인만 읽을 수 있게 만듭니다.
  - HDR 창이 화면 밝기 변화를 따라갑니다.

### Fixed
- **Photos could be deleted.** When an ordinary photo folder was opened with Open Library Folder, Grainy RS could treat numeric-named images in its `previews` and `thumbnails` subfolders (such as `2024.jpg`) as unused cache files and delete them. Grainy RS now removes only thumbnails it can prove it created.
- **Export never finished.** Exporting with metadata hung on some GPS positions (such as 2°23′0″).
- **Edits stay saved.** Edits saved just before a power cut or forced shutdown are kept. Two windows can no longer edit the same library at once.
- **Keywords were overwritten after switching libraries.** Fixed.
- **Safer Python-library import.**
  - An original file on an external drive can no longer be overwritten.
  - Switching libraries during the import no longer changes the wrong library.
  - Stopping the import midway no longer breaks camera profiles.
  - A photo whose original is offline no longer shows another photo's pixels.
- **RAW:**
  - Apple ProRAW DNGs open.
  - Mirrored RAWs get the right thumbnail orientation and size.
- **Editing:**
  - AI Denoise on its own is no longer skipped in the preview, in GPU exports, or by Copy and Sync.
  - The histogram and clipping warnings update at 1:1 zoom.
  - PV4 clarity no longer clips HDR highlights.
- **Files:**
  - Semi-transparent AVIF colours are correct.
  - AVIF and JPEG XL exports keep their camera metadata when reopened.
  - A malformed image file can no longer use excessive memory.
- **AI connection (MCP):** export, import and Auto Tone return a job id immediately instead of waiting for the work to finish. Exporting 10 RAWs used to block for about 40 seconds.
- **Ask AI:**
  - Your text is never read as a program option.
  - A program with the same name in the working folder is never run.
- **Responsiveness:**
  - Moving the pointer over the photo no longer stutters.
  - Selection drawing no longer slows down in large libraries.
- **Other:**
  - Turning off GPU acceleration also keeps exports off the GPU.
  - Cancelling a panorama merge ends quietly instead of showing an unrelated error.
  - Losing the graphics device is handled more safely.
- **macOS:**
  - A failed update no longer leaves the app missing.
  - The settings file is created readable only by you.
  - The HDR window follows changes in display brightness headroom.

On Windows, extract the complete ZIP and run `GrainyRS.exe` (or update directly from inside Grainy RS). On macOS (Apple Silicon and Intel, macOS 11.0+), open the universal DMG and drag `Grainy RS` into Applications. The matching `.sha256` files let you verify each download.
