## Grainy RS 0.3.0

The RAW Basic panel now fits all 15 sliders on a 1920 × 1080 Windows desktop at 125% scaling. After cropping or rotating, Fit view renders enough pixels to judge the visible detail. Use the arrow keys to make precise slider adjustments and hold Shift for larger steps.

- Search large libraries by filename or keyword using the catalog index. If a batch move to the recycle bin stops partway through, Grainy reconciles the originals and their virtual copies when the library reopens.
- Select overlapping photographs to merge a planar panorama, or select bracketed exposures to merge HDR. Grainy saves the result as a new 32-bit linear TIFF.
- Open AVIF and JPEG XL exports for further editing. JPEG XL export uses 16-bit lossless encoding. For animated JPEG XL, Grainy opens the first frame. AVIF import supports still images and grids. Some layered AVIF files require tile resizing and cannot yet be opened. HDR output includes 32-bit TIFF and 10-bit PQ AVIF. With the CLI, enable HDR in your settings JSON (`{"hdr":true}`) and pass it with `--settings`.
- On a compatible Windows HDR monitor, open the separate HDR preview window to inspect highlights above SDR white.
- Windows develops full-resolution Fujifilm X-Trans RAWs on multiple CPU cores. Tests on X-T2 and X-T3 files produced the same 16-bit pixels as the serial decoder. The X-T3 demosaicing step fell from 16.44 to 4.82 seconds on a Core i9-12900K.
- JPEG export at the original size uses fewer passes over sRGB pixels, including when dithering and automatic grayscale detection are enabled. In Windows tests with those options, total export time fell from 2.46 to 2.13 seconds for a Sony A7 III RAW and from 2.60 to 2.23 seconds for a Nikon Z6 RAW. The compressed JPEG image data matched in both cases.
- CPU color noise reduction uses less memory copying. On a 24 MP image, the detail stage took 17.95 seconds, down from 20.93 seconds, with identical output pixels.
- Create local subject and background masks. Windows can use an optional local U²-Net model. Tethered capture requires a camera and driver with remote shutter support.

On Windows, extract the complete ZIP and run `GrainyRS.exe`. On macOS, open the universal DMG and drag Grainy RS into Applications. The matching `.sha256` files let you verify each download.
