## Grainy RS 0.4.1

Grainy RS 0.4.1 fixes the runtime application icon on both Windows and macOS so Grainy's own `Gr` icon stays visible on the taskbar, title bar, Alt+Tab switcher, and macOS Dock.

- **Preserve Native App Icon on Windows & macOS**: Configured `eframe`'s root `ViewportBuilder` with `IconData::default()` (`window_state::default_viewport`) so `eframe`'s `AppTitleIconSetter` no longer overwrites the native window/taskbar icon (`grainy.ico` resource `1` on Windows, `GrainyRS.icns` in `Grainy RS.app` on macOS) with `egui`'s default icon on the first active frame. Added an automatic default-size fallback when loading Win32 icon resource `1` across DPI scales.
- **Instant Windows Explorer Icon Refresh After In-App Update**: `--finish-update` now calls `SHChangeNotify(SHCNE_UPDATEITEM)` on the replaced `GrainyRS.exe` so Windows Explorer clears any stale icon cache left over from older versions (such as `0.3.0`) immediately after updating in place.
- **Regression Guards**: Added a `window_state` unit test asserting the native icon preservation setting and a Windows release smoke check verifying `GrainyRS.exe` carries an embedded icon resource.

On Windows, extract the complete ZIP and run `GrainyRS.exe` (or update directly from inside Grainy RS). On macOS (Apple Silicon and Intel, macOS 11.0+), open the universal DMG and drag `Grainy RS` into Applications. The matching `.sha256` files let you verify each download.
