## Grainy RS 0.5.0

Grainy RS 0.5.0 completes **Phase 5 (Full-Pipeline GPU Parity, Instant RAW Import, Parallel GPU Export & Pro Studio UX)** and **Phase 6 (Apple ProRAW GainTableMap, Monochrome RAW, and Local GPU AI Denoise)**, adds Lightroom Classic–grade keyboard and multi-selection ergonomics, and ships a comprehensive 3-agent codebase stability & correctness hardening sweep.

### Phase 5 — Full GPU Coverage, Speed & Pro Studio UX
- **100% GPU Develop Pipeline (Phase 5A)**:
  - All 82 spectral **Film Looks** + separable Reflect101 **Halation** (`film.wgsl`), **Display Rendering Transform (DRT)** (`tone.wgsl`), and **Photo Filter** (`color.wgsl`) now stay zero-copy in VRAM with CPU-oracle parity.
  - **Zero-Copy GPU Local Masks** (`local.wgsl`): caches mask geometry in VRAM so live local-mask slider drags run directly on the GPU for both Fit and 1:1 viewport tiles.
  - **PV4 Single-Pass GPU Catmull-Rom Geometry Warp** (`geometry.wgsl`): straighten, rotation, flip, perspective, distortion (k1–k3), lateral CA, and crop run in one Bicubic GPU compute pass without CPU re-warping or PCIe re-upload.
- **Instant RAW Import & Parallel Thumbnails (Phase 5B)**:
  - Extracts embedded camera JPEG/RGB thumbnails from unedited RAW files via LibRaw (`gr_extract_thumb`) in ~1–3 ms with orientation-aware handling across Canon, Sony, Nikon, Leica, and Apple ProRAW.
  - Parallel thumbnail worker pool (`2–4` threads) with lock-free RAW decode concurrency and automatic orphan/LRU thumbnail cache pruning (`grainy_catalog::preview::prune_cache`, preserving live offline Smart Previews).
- **Multi-Core GPU-Accelerated Batch Export (Phase 5C)**:
  - Scaled native RS export concurrency (`rs_export_concurrency`, up to 8 workers) paired with `export_photo_with_gpu` so parallel worker threads decode RAW and encode output files concurrently while running SDR develop passes on the GPU.
- **Pro Studio UX (Phase 5D)**:
  - **Soft Proofing & Out-of-Gamut Warning**: `grainy-cms` adds `RenderingIntent`, Black Point Compensation (BPC), and `cmsCreateProofingTransformTHR` cyan gamut warnings, accelerated on GPU via 33³ tetrahedral monitor LUTs (`View → Soft Proofing`).
  - **Interactive 3-Way Color Grading Wheels**: side-by-side Shadows / Midtones / Highlights hue-saturation wheels alongside numeric sliders.
  - **8-Color Quick Swatch Bar** in Color Mixer and **Live Cursor `R / G / B %` Readout** in the Histogram (`<0.05 ms` 1×1 GPU texture readback).
  - **Native Dual-Monitor Secondary Window**: Reference and second-screen windows open as true OS native windows via `show_viewport_immediate`.

### Phase 6 — Modern RAW & Local GPU AI Denoise
- **Apple ProRAW / DNG 1.6 `ProfileGainTableMap` (Tag `52525`)**: parses and evaluates spatial luminance-adaptive tone gain maps natively during RAW development.
- **1-Channel Monochrome RAW & MakerNote Lens Fallback**: clean linear RGB expansion for monochrome sensors (Leica M Monochrom / Pentax Monochrome) plus LibRaw MakerNote lens identification when EXIF tag `42036` is absent.
- **Local GPU AI Denoise (`ai_denoise`, Detail Panel)**: opponent-space 7×7 collaborative 3×3-patch Non-Local Means denoiser running offline on the GPU (`ai_denoise.wgsl`) with `< 2e-5` GPU/CPU parity.

### Lightroom Classic UX & 3-Agent Bug Audit Hardening
- **Slider Numeric Box Arrow Fine-Adjustment**: click any slider's numeric box and use `↑/↓` (`Shift+↑/↓` for 10×) to live-adjust while keeping focus and text selected; `Enter` or blur commits one undo step, `Esc` reverts cleanly.
- **Filmstrip & Library Grid Multi-Selection**: full `Shift+Click` range selection, `Ctrl/Cmd+Click` toggle, `Ctrl/Cmd+Shift+Click` additive range, `Shift+Arrow` range expansion with auto-scroll, `Ctrl/Cmd+A`, and `Ctrl/Cmd+D`.
- **Comprehensive Stability & Correctness Fixes**:
  - *GPU & Engine*: fixed `"ProPhoto" -> "Luma Wide"` CMS profile mapping in GPU & CPU soft-proofing, `interp` NaN u32 underflow, Catmull-Rom border clamping, O(1) modular `reflect101` (eliminating DX12 TDR on narrow crops), PV3 clarity tile radius, tile-unsafe stage bypass (grain / wavelet / v4 clarity), GPU device-failure recovery, and tiled eyedropper loupe UV remapping.
  - *RAW, CMS, Codecs & Platform*: guarded macOS 12+ `maximumPotentialExtendedDynamicRangeColorComponentValue` with `respondsToSelector:` for macOS 11 Big Sur safety, fixed Metal HDR staging buffer race, eliminated LittleCMS 2.19 `EvalSegmentedFn` multi-thread data race via per-worker transform pooling, bounded TIFF LZW decoding to 1 GiB against zip bombs, fixed signed `SRATIONAL` EXIF GCD corruption and Olympus/Panasonic EXIF magic support, enforced JPEG APP1 65 KB EXIF limits on DNG exports, hardened XMP sidecar parsing (`allow_dtd: false`, 16 MiB cap), and added macOS `EXCHANGE` rename fallback on non-APFS volumes.
  - *UI/UX*: fixed 3-way grading wheel layout width, mask shortcut (`K`/`M`/`Shift+M`) premature deletion bug, preset load error retry storm, canvas tool keyboard leaking into modals/text fields, right-click canvas/curve misfires, off-window pointer release tracking, disconnected "Include crop & rotation in paste" checkbox, `EditState::undo()` Auto Sync broadcast on uncommitted drags, collection filter toolbar state, and macOS `Ctrl` shortcut collisions.

On Windows, extract the complete ZIP and run `GrainyRS.exe` (or update directly from inside Grainy RS). On macOS (Apple Silicon and Intel, macOS 11.0+), open the universal DMG and drag `Grainy RS` into Applications. The matching `.sha256` files let you verify each download.
