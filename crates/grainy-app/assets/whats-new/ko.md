# Grainy RS 변경 기록

업데이트 뒤 Grainy RS가 처음 열릴 때 보여 주는 변경 기록입니다(영어는 en.md). 새 버전마다 `## 버전 — 제목` 절을 이 파일과 en.md에 함께 더합니다. GitHub 릴리스 설명은 docs/releases에 있습니다.

## 0.5.3 — 창 크기 때문에 꺼지던 문제 수정

- **다른 프로그램이 창을 아주 크게 만들어도 꺼지지 않습니다.** 스크립트나 창 관리·화면 캡처 도구가 Grainy RS 창을 그래픽카드가 그릴 수 있는 크기(보통 16384~32768픽셀)나 모든 모니터를 합친 크기보다 크게 만들면 메시지 없이 꺼졌습니다. 이제 창이 모니터 크기로 돌아옵니다.
- 창을 잠깐 그리지 못한 뒤에도 화면이 검게 남지 않고 다시 그려집니다.

## 0.5.2 — 파이썬판 Grainy 라이브러리 가져오기

- **Grainy는 이제 Grainy RS로 이어집니다.** 파이썬판 Grainy는 0.6.9가 마지막이고, 새 기능과 수정은 Grainy RS에만 나옵니다.
- **파이썬판 라이브러리를 가져옵니다.** 라이브러리가 빈 상태로 처음 켜면 파이썬판 Grainy의 라이브러리(사진, 보정, 기록, 컬렉션, 썸네일, 카메라 프로필)를 가져올지 한 번 묻습니다. 파이썬판 라이브러리는 읽기만 하고 바꾸지 않습니다.
  - 파일 관리 메뉴 › '파이썬 Grainy 라이브러리 가져오기…'로 언제든 할 수 있습니다. 이미 사진이 있으면 먼저 묻고, 지금 라이브러리를 백업한 뒤 바꿉니다(파일 관리 › 카탈로그 복원으로 되돌림).
- **AI 연결:** Claude Code와 Codex 설치 명령이 예전 grainy 연결(파이썬판 등)을 Grainy RS 연결로 바꿉니다.
- 업데이트 뒤에 파이썬판의 달라진 점 대신 Grainy RS의 달라진 점을 보여 줍니다.

## 0.5.1 — 자동 색 세기 슬라이더, AI에게 시키기의 모델 선택

- **자동 색 세기 슬라이더가 돌아왔습니다.** 자동 색(Ctrl+Shift+U)을 적용하면 기본 패널의 버튼 줄 바로 아래에 '자동 색 세기'(0–100%) 슬라이더가 나타납니다.
  - 끄는 동안 색이 바로 바뀌고, 숫자 칸에서 ↑/↓(Shift: 10배)로 세밀하게 맞출 수 있습니다.
  - 고른 세기는 다른 사진과 여러 장 한꺼번에 적용할 때도 그대로 쓰이고, 되돌리기 한 번으로 취소됩니다.
- **AI에게 시키기에서 모델을 고를 수 있습니다.** 프로그램마다(Claude Code, Codex, Gemini CLI) 추천 모델 목록이 있고, 직접 입력하거나 프로그램 기본 모델을 쓸 수도 있습니다. AI 프로그램을 바꾸면 맞지 않는 모델 선택은 저절로 지워집니다.
- 설정 → AI 연결 (MCP)… 창에 'AI에게 시키기 (로그인·모델 선택)…' 버튼이 생겨, 로그인과 모델 선택을 바로 열 수 있습니다.

## 0.5.0 — 보정 전 과정 GPU 처리, 빠른 RAW 가져오기, AI 노이즈 제거, 여러 장 선택

- **보정의 모든 단계를 그래픽카드(GPU)가 처리합니다.** 필름 룩 82종과 할레이션, 디스플레이 렌더링 변환(DRT), 사진 필터, 부분 보정, 기울기·원근·렌즈 왜곡·자르기까지 GPU에서 계산해 슬라이더를 끌 때 더 빨리 반응합니다.
- **RAW를 빨리 가져옵니다.** 보정하지 않은 RAW는 카메라가 넣어 둔 미리보기로 썸네일을 바로 만들고, 썸네일 여러 장을 동시에 만듭니다. 쓰지 않는 썸네일은 저절로 정리합니다.
- **여러 장 내보내기가 빨라졌습니다.** 최대 8장을 동시에 처리하고, 보정은 GPU에서 합니다.
- **새로 생긴 것**
  - 보기·필터 → 소프트 프루핑: 출력할 색 프로필로 미리 보고, 그 범위를 벗어난 색을 표시합니다(블랙 포인트 보정 선택 가능).
  - 컬러 그레이딩 휠: 그림자·중간톤·하이라이트를 휠과 숫자 슬라이더로 함께 조절합니다.
  - 색상 혼합의 8색 빠른 견본, 히스토그램에 마우스 위치의 R·G·B % 표시.
  - 두 번째 화면이 운영체제의 별도 창으로 열립니다.
  - Apple ProRAW(DNG 1.6)의 밝기 맵과 흑백 센서 RAW(라이카 M 모노크롬 등)를 지원합니다.
  - 디테일 패널의 AI 노이즈 제거: 인터넷 없이 이 컴퓨터의 GPU에서 처리합니다.
- **손에 익은 조작**: 슬라이더 숫자 칸에서 ↑/↓로 바로 조절(Enter로 적용, Esc로 취소). 필름 스트립과 라이브러리 격자에서 Shift·Ctrl(⌘) 클릭, Shift+방향키, Ctrl+A(모두 선택), Ctrl+D(선택 해제)로 여러 장을 고릅니다.
- GPU, RAW, 색 관리, 파일 형식, 화면 곳곳의 오류를 많이 고쳤습니다. 좁게 자른 사진에서 그래픽 드라이버가 멈추던 문제, macOS 11에서 꺼질 수 있던 문제 등이 포함됩니다.

## 0.4.1 — 작업 표시줄과 Dock에 Grainy 아이콘이 제대로 보입니다

- Windows 작업 표시줄·제목 표시줄·Alt+Tab과 macOS Dock에서 Grainy 아이콘(Gr) 대신 기본 아이콘이 보이던 문제를 고쳤습니다.
- 앱 안에서 업데이트한 뒤 Windows 탐색기가 예전 아이콘을 계속 보여 주던 문제를 고쳤습니다.

## 0.4.0 — 훨씬 빠른 미리보기, 프로세스 4, 큰 라이브러리, 좋아진 AI 선택

- **슬라이더 반응이 크게 빨라졌습니다.** 미리보기를 그래픽카드 메모리에서 바로 화면에 그리고, 모니터 색 프로필 변환도 GPU에서 합니다. RTX 3070과 Display P3 모니터에서 4000×2667 사진의 지연이 414 ms에서 11 ms로 줄었습니다.
- **1:1로 확대하면 보이는 부분만 계산합니다.** 4500만 화소 사진에서 1:1 슬라이더 지연이 930 ms에서 10 ms 아래로 줄었습니다.
- **프로세스 4 · Grainy RS 네이티브**: 카메라 보정에서 고르는 새 처리 방식입니다. 날아간 하이라이트 복원, 더 넓은 하이라이트·그림자 조절, 후광 없는 부분 대비, 텍스처, 디헤이즈, 노이즈 제거가 좋아졌습니다. 프로세스 3으로 한 보정은 그대로입니다.
- **큰 라이브러리가 빨라졌습니다.** 사진 10만 장의 색인과 검색이 73초에서 1.5초로 줄었고, 폴더 전환도 훨씬 빨라졌습니다.
- **AI 선택이 좋아졌습니다.** 머리카락·털 같은 가는 경계를 더 잘 따라가고, '인물 피부 선택'이 새로 생겼습니다. Windows는 그래픽카드·NPU를 쓰고, macOS는 따로 받을 것 없이 기본 기능으로 처리합니다.
- **macOS HDR 모니터 창**: MacBook Pro XDR 같은 HDR 화면에서 별도 HDR 미리보기 창을 열 수 있습니다.
- 색 관리, 내보낼 때 촬영 정보 보존(Canon CR3, Fujifilm RAF), AVIF 내보내기 속도, 업데이트의 안정성을 높였습니다.

## 0.3.0 — RAW 기본 패널, 파노라마·HDR 합치기, AVIF·JPEG XL, 빨라진 X-Trans

- RAW 기본 패널의 슬라이더 15개가 1920×1080(배율 125%) Windows 화면에 모두 들어갑니다. 방향키로 슬라이더를 세밀하게, Shift와 함께 크게 움직입니다.
- 자르거나 회전한 뒤에도 화면 맞춤 보기가 세부를 판단할 만큼 선명합니다.
- 큰 라이브러리에서 파일 이름이나 키워드로 빨리 찾습니다. 휴지통으로 옮기다 중간에 멈춰도 다음에 라이브러리를 열 때 원본과 가상 사본을 맞춰 정리합니다.
- 겹치게 찍은 사진은 평면 파노라마로, 노출을 달리 찍은 사진은 HDR로 합칠 수 있습니다. 결과는 새 32비트 TIFF로 저장됩니다.
- AVIF·JPEG XL 파일을 열어 다시 보정할 수 있고, JPEG XL은 16비트 무손실로 내보냅니다. HDR로 내보내기(32비트 TIFF, 10비트 PQ AVIF)도 됩니다.
- Windows의 HDR 모니터에서는 별도 HDR 미리보기 창으로 SDR 흰색보다 밝은 부분을 확인할 수 있습니다.
- Fujifilm X-Trans RAW를 여러 CPU 코어로 처리해 빨라졌습니다(X-T3 디모자이크 16.4초 → 4.8초). JPEG 내보내기와 색 노이즈 제거도 빨라졌습니다.
- 피사체·배경 부분 선택을 만들 수 있습니다. 테더 촬영에는 원격 촬영을 지원하는 카메라와 드라이버가 필요합니다.
