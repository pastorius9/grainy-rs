pillow-default-font.ttf

The caption font of the contact sheets when the system has none of the fonts the Python Grainy looks for (on macOS,
usually): Pillow's built-in font, which `ImageFont.load_default(size)` decodes in Pillow 12.3.0
(`PIL/ImageFont.py`). The bytes are copied unchanged from there (12,676 bytes, SHA-256
69853909b940023570964e29cffe30da95aea8de3627736b5cd15ab30143169f; tools/golden/gen_mcp_builtin_font.py checks
them against the installed Pillow).

The font is a subset of Aileron Regular by Sora Sagano, <http://www.dotcolon.net>, version 1.102. Its copyright
notice reads "No Rights Reserved." (Aileron is published as public domain, Creative Commons CC0 1.0 Universal,
<https://creativecommons.org/publicdomain/zero/1.0/>).
